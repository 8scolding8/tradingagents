# PRD · 宏观雷达（美股市场个人主页）

> 本文件冻结「做什么 / 不做什么 / 怎样算成功」三个边界，避免 AI 在执行中扩大范围。

## 1. 项目目标
- 建立一个**长期可更新**的美股宏观分析个人主页，作为公开学习档案与作品集入口。
- 把 IMA 121 知识库最新研报的结构化版本对外可见，降低阅读与检索成本。
- 用规范化 AI 开发流程（Vibe → Spec → Harness）完成发布与提交。

## 2. 用户与场景
- **目标访问者**：同学、教师、未来项目伙伴、招聘初筛者。
- **访问目的**：快速判断「这是谁、在研究什么、最近读什么」。
- **首批检索项**：个人简介、能力与兴趣、最近读过的研报、可公开联系方式。

## 3. 信息架构
- 严格五区块：Hero / About / Skills / Projects / Contact。
- Projects 区块以**卡片列表**承载研报，每张卡片含：分类标签、标题、日期、来源、摘要、**原文摘录（多段）、核心观点、逻辑链、关键数据可视化、关键数据完整列表、结论**。

## 4. 本期范围（必须做）
- 静态单页（HTML + CSS + 原生 JS），无前端框架、无 npm 依赖。
- GitHub Pages 部署，移动端优先、桌面端良好。
- ≥3 次有意义 commit；PRD / Design / Checklist / Report / 截图齐全。
- 至少 4 张证据截图：桌面首页、移动首页、Projects 展开（含原文+图表）、报告生成 / 发布证据。
- 至少 12 篇宏观研报，每篇含原文摘录、核心观点、逻辑链、关键数据可视化、结论；覆盖货币政策 / 通胀 / 就业 / 利率 / 财政 / 行业 / 估值 / 地缘 等主题。

## 5. 本期不做（明确禁止）
- 任何登录、注册、数据库、评论、收藏、用户状态。
- 任何支付、订阅、广告、第三方追踪脚本。
- 直连行情 API；不写入任何 API Key、Token、私人凭据。
- 直连 IMA 121 知识库服务端；数据先离线提炼为 JSON 后再嵌入。

## 6. 数据源边界
- **TradingAgents**：仅作项目案例陈列（About / Skills 引用结构与截图），**不调用**其 Python 运行时，不安装其依赖。
- **IMA 121 知识库**：拉取最新宏观研报 → 人工提炼为结构化 JSON → 嵌入静态页面；保留来源标注；不二次分发原文。
- **行情 / 图表**：首期不接入；如需简单展示用 CSS 柱状或纯文本，不引入 Chart.js。

## 7. 成功标准
- 桌面（≥1280px）与移动端（375×812）下五区块完整可见、无横向溢出。
- 全部链接可点击，GitHub Pages 公网 URL 正常打开。
- 三份文档与最终网站一致；至少 3 次有意义 commit。
- `grep -r "API_KEY\|api_key\|secret" site/` 结果为空。
- 隐私边界：邮箱 / 微信 / 电话 / 凭据一律不入仓。
