关于

本站是一个面向美股市场宏观分析的个人项目主页，以「数据可追溯、判断有边界」为基本要求。

项目来源

代码结构与多智能体思路参考开源项目 TauricResearch/TradingAgents（仅作案例陈列，不调用其 Python 运行时）。

数据来源

首期内容来自 IMA 知识库中 121 知识库 的最新宏观研报，由人工提炼为结构化 JSON 后嵌入，确保站点纯静态可发布。

方法论

每篇研报输出四要素：摘要、核心观点、关键数据、结论。所有数据均标注来源，未对原文进行二次分发。

能力

围绕宏观研报阅读与判断需要，建立从数据到观点的可验证链路。

  • 图表核读：识别 FOMC 点阵图、CPI/PCE 同比、收益率曲线信号。
  • 利率路径：跟踪 OIS、SOFR 远期与 2s10s 利差，判断市场对末次加/降息定价。
  • 行业映射：把宏观变量映射到板块（金融、地产、科技、能源、可选消费）。
  • 汇率与跨境：DXY、美日利差、新兴市场资金流向对纳指/标普的间接传导。
  • 风险识别：流动性、信用利差、VIX 期限结构三类指标的早期信号。
  • 结构化输出：把研报压缩为四要素结构，便于横向比较和回溯。
